# HCl 누출 대응 VR 나레이션·TTS 시나리오 제작 자료

작성 기준일: 2026-08-14  
작업 역할: Integration  
대상 흐름: `Start → PPE → PreEntry → LeakResponse → Complete`

## 1. 이 문서의 목적

이 문서는 현재 Unity 프로젝트의 실제 상태 전이, 버튼 입력, 완료 조건을 기준으로 GPT에게 새 시나리오 대본을 요청하기 위한 정본 자료다.

목표는 다음 세 가지다.

1. 실제로 할 수 없는 행동을 먼저 말하지 않는다.
2. 성공 확인과 다음 행동을 중복해서 말하지 않는다.
3. 사용자가 지금 해야 할 행동과 안전상 중요한 결과만 말한다.

이 문서는 대본 제작 자료이며, 기존 코드·Scene·AudioClip을 직접 변경하지 않는다.

## 2. 전체 Scene 구조

| 순서 | Unity Scene | 사용자 목적 | 음성 정책 |
|---|---|---|---|
| 0 | `Assets/Scenes/01_App.unity` | 공용 XR 및 전체 흐름 유지 | 음성 없음 |
| 1 | `Assets/Scenes/03_Start.unity` | 전체 훈련 또는 개별 Stage 선택 | 음성 없음 |
| 2 | `Assets/Scenes/04_PPE.unity` | PPE와 현장 대응 장비 준비 | 행동 안내 중심 |
| 3 | `Assets/Scenes/05_PreEntry.unity` | 진입 전 풍향·농도·P-102 상태 확인 | 측정 결과와 행동 안내 중심 |
| 4 | `Assets/Scenes/06_LeakResponse.unity` | 누출 차단·흡착·오염물 회수 | 안전 상태와 행동 안내 중심 |
| 5 | `Assets/Scenes/07_Complete.unity` | 완료 결과와 재시작 선택 | 음성 없음 |

전체 훈련 외에도 `PPEOnly`, `PreEntryOnly`, `LeakResponseOnly` 진입이 가능하다. 따라서 각 Stage의 첫 안내는 이전 Stage를 경험하지 않은 사용자도 이해할 수 있어야 한다. 다만 공통 조작을 장황하게 전부 다시 설명하지는 않는다.

## 3. 현재 음성량과 확인된 문제

### 3.1 현재 음성량

| Stage | 현재 성공 경로 음성 | 길이 | 비고 |
|---|---:|---:|---|
| PPE | 27개 | 93.400초 | 미사용 이동 Cue 1개와 오류·보정 Cue 8개는 별도 |
| PreEntry 전체 훈련 | 21개 | 154.332초 | 별도로 음성 없는 자막 단계 1개 존재 |
| LeakResponse | 필수 21개 | 177.320초 | 15초 무진행 알림 2개와 오류 3개는 별도 |
| 합계 | 최소 69개 | 425.052초 | 약 7분 5초, 사용자 행동 시간 제외 |

LeakResponse의 1~23번 진행용 파일 전체는 183.770초다. 이 중 16번과 19번은 15초 동안 진행이 없을 때만 재생되는 알림이다.

### 3.2 우선 수정해야 할 불일치

1. **PreEntry 압력 감소 안내와 실제 완료 조건이 다르다.**
   - `WaitPressureDecrease` 음성은 압력을 3초간 확인하라고 말한다.
   - 실제로 이 단계는 감압 연출이 끝날 때까지 자동 대기한다.
   - 실제 시선 확인은 다음 `VerifyPressureDecrease` 단계에서 2초간 수행한다.
   - 그러나 `VerifyPressureDecrease`에는 AudioClip이 연결되어 있지 않아 자막만 나오고 음성은 나오지 않는다.

2. **LeakResponse 흡착재 안내는 현재 가방 Grip 조작과 일치해야 한다.**
   - 흡착삭과 흡착패드는 가방 영역에서 Grip을 눌렀다 놓아 꺼낸다.
   - 8번과 10번 나레이션은 첫 Grip 배출과 다음 Grip 잡기를 모두 말해야 한다.
   - 사용자는 물체가 어디서 나오는지 알 수 없다.

3. **PPE 대응가방은 한 문장으로 설명하기 어려운 3단계 조작이다.**
   - Grip으로 가방 선택 → 왼손 Y로 내용물 확인 → Grip으로 준비 완료 순서다.
   - 현재 안내는 Y 확인만 강조해 선택과 최종 Grip이 불명확하다.

4. **성공 확인과 다음 행동이 별도 음성으로 연속 재생된다.**
   - PPE는 거의 모든 장비마다 “착용했습니다” 다음에 다음 장비 안내가 나온다.
   - LeakResponse는 “완료되었습니다”와 다음 행동 안내가 연속으로 나오는 구간이 많다.
   - PreEntry 종료부는 정지 확인, 압력 감소 확인, 안전 확인 완료, 접근 금지 해제 확인, 다음 구역 이동이 연속 재생된다.

5. **실제 행동이 필요 없는 대기 구간에서 행동처럼 말하는 부분이 있다.**
   - PreEntry `WaitWindChange`는 풍향계가 자동으로 회전한다.
   - 현재 음성은 계속 확인하라고 하지만, 이 단계 자체에는 시선 유지 완료 조건이 없다.

6. **초반 음성이 너무 길어 사용자가 기다리는 시간이 길다.**
   - PPE는 시작 직후 7개 안내가 연속 재생된다.
   - LeakResponse는 현장 도착과 흡입측 밸브 안내가 끝날 때까지 약 25초 동안 행동을 시작할 수 없다.

## 4. 새 대본 공통 작성 규칙

### 4.1 반드시 지킬 규칙

1. 한 Cue에는 하나의 현재 목표만 넣는다.
2. 한 Cue는 최대 두 문장, 목표 4~8초, 절대 상한 10초로 작성한다.
3. 행동 안내는 해당 행동이 가능해지는 직전 또는 가능해진 시점에만 재생한다.
4. 사용자가 알아야 할 숫자, 대상, 버튼, 유지 시간은 생략하지 않는다.
5. 단순 성공 확인은 음성 대신 체크 표시, 효과음, 햅틱으로 처리한다.
6. 다음 행동 안내가 이전 행동의 성공을 자연스럽게 보여주면 별도 성공 문장을 만들지 않는다.
7. TTS와 자막은 의미와 정보 순서가 같아야 한다.
8. 오류 Cue는 실제 오류 행동이 발생했을 때만 재생한다.
9. 대기 알림은 진행이 없을 때만 재생하고, 이미 음성이 재생 중이면 쌓아 두지 않는다.
10. 전체 훈련 기준 주요 음성 총량은 4분 이내를 목표로 한다.

### 4.2 음성으로 말하지 않을 내용

- 화면만 보아도 알 수 있는 “선택되었습니다”, “완료되었습니다”의 반복
- 현재 행동과 관계없는 사고 배경, 교육 목적, 동기 부여 문장
- 같은 버튼 사용법의 반복
- “이제”, “다음으로”, “계속해서”만 추가한 연결용 문장
- 시스템 상태 설명, 로딩 설명, Scene 이름, 개발 용어
- 실제 완료 조건에 없는 시선 유지·버튼 입력·대기 시간
- 아직 활성화되지 않은 장비나 상호작용

### 4.3 용어와 표기 고정

| 개념 | 자막 표기 | TTS 발음용 표기 원칙 |
|---|---|---|
| 설비 태그 | `P-102` | 모든 파일에서 한 가지 발음으로 통일. 엔진 테스트 후 `피 다시 일 공 이` 또는 현장 표준 발음으로 확정 |
| 초기 농도 | `3.0 ppm` | `삼 점 영 피피엠` |
| 감소 농도 | `0.8 ppm` | `영 점 팔 피피엠` |
| 기체 농도 | `염화수소 농도` | 같은 표현 유지 |
| 바닥 누출액 | `염산`, `누출액` | 같은 표현 유지 |
| 대응가방 | `대응가방` | `대응 가방`처럼 자연스럽게 발음 가능 |
| Absorbent Sock | `흡착삭` | `흡착 삭` |
| Absorbent Pad | `흡착패드` | `흡착 패드` |
| Recovery Tongs | `회수용 집게` | 같은 표현 유지 |
| Waste Container | `유해폐기물 수거용기` | 같은 표현 유지 |
| Grip | `Grip` | `그립` |
| Trigger | `Trigger` | `트리거` |
| 버튼 | `A`, `B`, `Y` | `에이`, `비`, `와이` |

`염화수소`와 `염산`을 서로 바꾸지 않는다. PreEntry의 가스 측정은 염화수소 농도이고, LeakResponse의 바닥 누출액과 흡착 대상은 염산이다.

## 5. Start Scene 대본 기준

### Scene 목적

사용자가 다음 네 가지 중 하나를 선택한다.

- 전체 훈련
- PPE 착용 교육
- 현장 진입 전 확인절차
- P-102 염산 누출 대응

### 음성 결론

`NO_VOICE`

메뉴 제목과 설명만으로 선택이 가능하다. 시작할 때 “훈련할 과정을 선택하세요”를 음성으로 반복하지 않는다.

## 6. PPE Scene 상세 자료

### 6.1 실제 조작 계약

- 일반 PPE: 노란 외곽선 장비를 가리킴 → Grip 한 번으로 선택 → 다시 Grip으로 착용
- 선택 취소: 오른손 B
- 대응가방: Grip으로 선택 → 왼손 Y로 내용물 확인 → Grip으로 준비 완료
- 외부 보호장갑 착용 후 수거용기: 수거용기를 바라보면 자동 선택 → Grip으로 준비
- Stage 완료 후 이동: 오른손 A
- TTS 재생 중에는 장비 상호작용이 차단된다.

### 6.2 실제 준비 순서

1. 속장갑
2. 내산성 화학보호복
3. 내화학 안전장화
4. 전면형 호흡보호구
5. 대응가방
6. 안면보호구
7. 외부 보호장갑
8. 유해폐기물 수거용기

## 7. PreEntry Scene 상세 자료

### 7.1 실제 시나리오 흐름과 완료 조건

1. 시작 안내 종료 후 자동으로 측정기 꺼내기 단계 진입
2. 가방 위에서 왼손 Grip을 눌렀다 놓아 측정기를 올린 뒤 다시 왼손 Grip으로 잡기
3. 측정기 화면을 보며 왼쪽 Trigger를 3초 유지해 초기 농도 측정
4. `3.0 ppm` 결과 확인 후 자동으로 풍향 확인 단계 진입
5. 초기 풍향계를 3초간 응시
6. 위험 풍향 안내 종료 후 풍향계가 자동 회전
7. 바뀐 풍향계를 3초간 응시
8. 측정기 화면을 보며 왼쪽 Trigger를 3초 유지해 재측정
9. `0.8 ppm` 결과 확인
10. 왼손 Grip으로 측정기 수납
11. 오른손 A로 P-102 패널 위치로 이동
12. 압력 표시 2초 응시
13. 온도 표시 2초 응시
14. RUN 표시 2초 응시
15. 오른손을 파란 영역에 넣고 오른쪽 Trigger로 정지
16. STOP 표시 2초 응시
17. 압력 감소 연출 완료까지 대기
18. 감소한 압력 표시 2초 응시
19. 접근 금지 표시 해제 후 오른손 A로 다음 구역 이동

### 7.2 권장 주요 Cue

## 8. LeakResponse Scene 상세 자료

### 8.1 실제 시나리오 흐름과 완료 조건

1. 현장 도착 안내
2. 흡입측 밸브를 반복해서 Grip으로 잡고 시계 방향으로 돌려 100% 폐쇄
3. 토출측 밸브를 같은 방식으로 100% 폐쇄
4. 플랜지 누출 지점을 3초 연속 응시해 누출 감소 확인
5. 가방 영역에서 Grip을 눌렀다 놓아 흡착삭 꺼내기
6. 흡착삭 공급 물체를 Grip으로 잡아 반투명 위치 근처에 놓기
7. 가방 영역에서 Grip을 눌렀다 놓아 흡착패드 꺼내기
8. 흡착패드 공급 물체를 Grip으로 잡아 반투명 위치 근처에 놓기
9. 잔류 염산 흡수 완료까지 대기
10. 수거용기 뚜껑을 열어 옆 거치 Ghost에 놓기
11. 회수용 집게를 Grip으로 잡기
12. Trigger로 흡착패드 3개를 먼저 집어 수거용기에 넣기
13. Trigger로 흡착삭 4개를 집어 수거용기에 넣기
14. 집게를 옆 거치대에 반납
15. 뚜껑을 수거용기 위 폐쇄 Ghost에 놓기
16. 수거용기 폐쇄 완료 후 Stage 완료

흡착삭 설치 공급 물체 하나가 Scene에 배치된 흡착삭 4개를 한 번에 설치하고, 흡착패드 공급 물체 하나가 패드 3개를 한 번에 설치한다. 회수 단계에서는 설치된 총 7개를 각각 집게로 수거한다.

## 9. Complete Scene 대본 기준

### Scene 목적

- 완료한 Stage 표시
- 동일 훈련 다시 하기
- 다른 훈련 선택하기
- 시작 화면으로 돌아가기

### 음성 결론

`NO_VOICE`

LeakResponse 또는 개별 Stage의 최종 Cue가 이미 완료를 알린다. Complete Scene에서 다시 “훈련을 완료했습니다”를 읽지 않는다.

## 10. GPT가 절대 새로 만들면 안 되는 내용

- 존재하지 않는 장비, 밸브, 센서, 버튼, 메뉴
- 손 소독, 무전 보고, 관리자 승인, 대피 집결 등 현재 구현에 없는 절차
- 측정값 `3.0 ppm`, `0.8 ppm` 이외의 임의 수치
- 밸브 폐쇄 순서를 토출측부터 시작하도록 변경하는 내용
- 흡착삭보다 흡착패드를 먼저 설치하는 내용
- 회수 단계에서 흡착삭을 패드보다 먼저 수거하는 내용
- 흡착재를 손으로 집도록 유도하는 내용
- Scene 전환이나 로딩을 사용자가 직접 수행한다고 말하는 내용
- 코드 이벤트 이름을 사용자에게 읽는 내용

## 11. GPT에 그대로 넣을 요청 프롬프트

아래 프롬프트와 이 문서 전체를 함께 제공한다.

```text
당신은 산업안전 VR 교육용 한국어 나레이션 작가다.

첨부한 “HCl 누출 대응 VR 나레이션·TTS 시나리오 제작 자료”만 사실의 근거로 사용하라. 자료에 없는 장비, 안전 절차, 버튼, 수치, 완료 조건을 추가하지 마라.

목표:
1. 실제 Unity 행동과 정확히 맞는 대본을 만든다.
2. 사용자가 지금 해야 할 행동과 안전상 중요한 결과만 말한다.
3. 성공 확인과 다음 행동을 중복 발화하지 않는다.
4. Start와 Complete Scene에는 음성을 만들지 않는다.
5. 전체 훈련 주요 음성을 4분 이내로 설계한다.

작성 규칙:
- 한 Cue는 하나의 현재 목표만 다룬다.
- 한 Cue는 최대 두 문장, 목표 4~8초, 절대 상한 10초다.
- 버튼, 손, 유지 시간, 대상, 수량이 행동 성공에 필요하면 반드시 말한다.
- 단순 성공 확인은 NO_VOICE로 표시하고 UI/효과음으로 보낸다.
- TTS 원문과 자막은 의미와 정보 순서를 완전히 같게 한다.
- 자막에는 P-102, 3.0 ppm, 0.8 ppm, Grip, Trigger, A/B/Y 표기를 사용한다.
- TTS 원문에는 자연스러운 한글 발음을 별도 표기한다.
- 염화수소 가스 농도와 염산 누출액을 혼용하지 않는다.
- “이제”, “다음으로”, “확인했습니다” 같은 연결용 문장을 습관적으로 붙이지 않는다.
- 오류와 무진행 알림은 정상 진행 대본에 섞지 말고 별도 표로 작성한다.
- 자료에서 NO_VOICE 또는 통합 대상으로 지정한 이벤트에 새 설명을 붙이지 않는다.

먼저 아래 열을 가진 Cue Sheet를 작성하라.

scene,
new_cue_id,
current_event_or_step,
trigger_condition,
voice_type(primary|critical_status|error|idle|NO_VOICE),
tts_text_ko,
subtitle_text_ko,
target_seconds,
required_user_action,
completion_condition,
must_not_play_with,
implementation_note

그 다음 아래 검수 결과를 작성하라.
- 실제 버튼과 손이 모두 맞는지
- 실제 유지 시간이 모두 맞는지
- 성공 확인 중복이 없는지
- 행동 활성화 전에 말하는 Cue가 없는지
- TTS와 자막의 수치·대상·행동 순서가 같은지
- 정상 진행 중 총 예상 음성 시간이 몇 초인지

문체는 침착하고 단호한 현장 안전 안내로 유지하되 위협적이거나 과장되게 쓰지 마라.
```

## 12. 대본 납품 후 검수 체크리스트

### 전체

- [ ] Start와 Complete는 `NO_VOICE`인가
- [ ] 전체 훈련 주요 음성이 4분 이내인가
- [ ] 한 Cue가 10초를 넘지 않는가
- [ ] TTS가 끝나야 행동 가능한 구조라면 불필요하게 긴 Cue가 없는가
- [ ] 자막과 음성의 숫자, 손, 버튼, 대상 순서가 같은가
- [ ] Stage 전환 시 이전 음성이 남지 않는가

### PPE

- [ ] Grip 1회 선택, Grip 재입력 착용이 정확한가
- [ ] 대응가방의 `선택 → Y 확인 → Grip 준비` 순서가 정확한가
- [ ] 외부 보호장갑 후 수거용기를 시선으로 선택한다는 점이 정확한가
- [ ] 장비별 성공 음성이 제거되었는가
- [ ] 마지막 A 이동 안내가 1회만 나오는가

### PreEntry

- [ ] 측정기는 왼손 Grip으로 꺼내고 다시 왼손 Grip으로 수납하는가
- [ ] 두 농도 측정 모두 화면 응시와 왼쪽 Trigger 3초를 요구하는가
- [ ] 풍향 응시는 각 3초인가
- [ ] P-102 패널 응시는 각 2초인가
- [ ] 감압 대기와 감압 후 2초 시선 확인이 별도 Cue로 나뉘는가
- [ ] `VerifyPressureDecrease`에 실제 AudioClip을 추가하도록 표시했는가
- [ ] 종료부 완료 문장이 한 번만 나오는가

### LeakResponse

- [ ] 흡입측 밸브가 먼저인가
- [ ] 밸브는 시계 방향 회전과 100% 게이지 완료를 말하는가
- [ ] 플랜지 응시는 3초인가
- [ ] 흡착삭·패드를 가방에서 Grip으로 꺼내고 다음 Grip으로 잡는다고 말하는가
- [ ] 설치는 흡착삭 후 흡착패드 순서인가
- [ ] 회수는 패드 3개 후 흡착삭 4개 순서인가
- [ ] 오염 흡착재 직접 접촉 금지와 집게 사용이 유지되는가
- [ ] 집게 반납 후 뚜껑 폐쇄 순서인가
- [ ] 중간 성공 Cue가 UI·효과음으로 이동했는가
